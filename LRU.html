How it Works:

Topic: LRU (Least Recently Used) cache stores data as Key-Value pairs. It keeps the most recently accessed items at the front (MRU). When the capacity is reached, it deletes the item at the very end (LRU) to make room for new data.

1. Put: Enter a key and value. If the key exists, it updates the value and moves to the front. If new, it adds it to the front.
2. Get: Enter a key to find its value. If found, it moves to the front because it was "recently used".
3. Capacity: Change the limit at any time. If you decrease it, the oldest items are automatically evicted.
